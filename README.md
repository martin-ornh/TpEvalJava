# PetStore -> Tp évalué 

**Par** : Martin ORNH


## But du TP :

Modélisation d'une animalerie avec mapping JPA, relations d'héritage et manipulation via EntityManager.

## Prérequis :

- Java 17+
- Maven 25
- PostgreSQL 14+

## Configuration BDD :

```
CREATE DATABASE petstore;
```
Puis rajouter les identifiants de la base dans le persistence.xml.


## Lancer le projet

Pour lancer le projet, il faudra run le Main.java, contenant toutes les requêtes pour initialiser la base et ajouter des données.
( Correction pour le lancer directement car commentaires pour les tests)

## Dépendances

Hibernate ORM --> 6.4.4.Final
PostgreSQL Driver --> 42.7.3
Java --> 17+
